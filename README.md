# G Fragrances

Tienda de fragancias construida con Next.js y TypeScript.

## Ejecutar localmente

```bash
npm install
npm run dev
```

La demo incluye catálogo, filtros, vistas de producto, carrito persistente, checkout y enlaces de WhatsApp. Para el despliegue comercial se debe conectar la capa de catálogo a Supabase/PostgreSQL y configurar las credenciales de pagos, correo, WhatsApp y administración.
